# app-ui — หน้าจอแอปแบบมืออาชีพ

ดัดแปลงจาก skill mobile-app-ui และ Design Kit "App Builder" ของ IDE

## โครงหน้าจอ
- หน้าแรกตอบคำถาม "ตอนนี้ต้องทำอะไร": การกระทำหลักหนึ่งอย่างเด่นที่สุด อยู่ครึ่งล่างของจอ (นิ้วโป้งถึง)
- เมนูล่าง 3–5 เมนู ไอคอน + ข้อความทุกเมนู เมนูที่เปิดอยู่ใส่ `aria-current="page"`
- หน้าที่ "ลึกลงไป" (รายละเอียด ฟอร์ม) มีปุ่มย้อนกลับที่มี `aria-label="ย้อนกลับ"`
- สลับหน้าด้วยการซ่อน/แสดง `<section>` ตาม `location.hash` (`#home`, `#detail`) ปุ่มย้อนกลับของเบราว์เซอร์จึงใช้ได้

## สูตรหน้าจอที่ใช้บ่อย
- **จอง / นัดหมาย**: ค้นหา → รายการตัวเลือก (เวลา ราคา หน่วย) → เลือก → ฟอร์ม → หน้าสรุปก่อนยืนยัน → สำเร็จพร้อมเลขอ้างอิง
- **รายการ / สต็อก / งาน**: ช่องค้นหา + ตัวกรอง (ชิป) → รายการ (ชื่อ ข้อมูลย่อ สถานะเป็นข้อความ) → ปุ่ม + เพิ่ม
- **การเงิน / แต้ม**: ยอดใหญ่ด้านบน → ปุ่มลัด → รายการล่าสุด จำนวนเงินมี + / − เสมอ
- **แดชบอร์ด**: การ์ดตัวเลข 3–4 ใบ (ชื่อ ค่า หน่วย เทียบช่วงก่อน) → กราฟแท่งด้วย CSS → ตารางล่าสุด

## ส่วนประกอบ
- การ์ด: พื้นต่างจากพื้นหลังเล็กน้อย มุมโค้งเท่ากันทั้งแอป เงาบาง
- ชิปตัวกรอง: `<button aria-pressed="true|false">` เลือกแล้วเปลี่ยนสีพื้น
- แผ่นล่าง / กล่องยืนยัน: ใช้ `<dialog>` + `showModal()` ปิดได้ด้วย Esc และปุ่มยกเลิก
- ข้อความแจ้งสั้น (toast): `<div role="status" aria-live="polite">` แสดง 2–3 วินาที
- โครงโหลด (skeleton): กล่องสีเทาแทนเนื้อหาระหว่างโหลด
- หน้าว่าง: ไอคอน + หนึ่งประโยคบอกเหตุผล + ปุ่มเริ่ม

## โทนสีและตัวอักษร
- กำหนดใน `:root`: `--bg --surface --ink --muted --line --accent --accent-ink --danger --success --radius`
- ตัวหนังสือบนสีเน้นต้องอ่านชัด (เหลือง/เขียวอ่อนใช้ตัวดำ)
- ฟอนต์ไทย: `font-family: system-ui, 'Noto Sans Thai', sans-serif;` ขนาดเนื้อหา 16px ขึ้นไป บรรทัด 1.6
- ใช้ไอคอน SVG เส้นเดียวกันทั้งแอป ไม่ใช้อีโมจิแทนไอคอน

## การตอบสนอง
- ทุกการกดเปลี่ยนสถานะที่เห็นได้ภายในทันที (ปุ่มกด, toast, รายการเปลี่ยน)
- ลบ: ยืนยัน หรือ toast พร้อม "เลิกทำ" 5 วินาที
- การกระทำที่ปัดได้ ต้องมีปุ่มทำแทนได้ด้วย
- แอนิเมชัน 150–300ms และหยุดเมื่อ `prefers-reduced-motion: reduce`

## จอกว้าง
- ตั้งแต่ 900px เมนูล่างกลายเป็นเมนูข้าง เนื้อหากว้างไม่เกิน ~1040px วางสองคอลัมน์ (รายการ + รายละเอียด)
