# app-fix — แก้บั๊กจากหลักฐาน

ดัดแปลงจาก skill systematic-debugging และ frontend-debugging-playbook ของ IDE

## ความจริงที่ต้องยอมรับ
AI ในแพลตฟอร์มไม่ได้เปิดแอปและไม่เห็น Console การแก้บั๊กจึงดีได้เท่ากับหลักฐานที่ได้รับ แอปทุกตัวจึงมีตัวจับ error (SKILL.md หัวข้อ 6) ที่ทำ "รายงานบั๊ก" ให้ผู้ใช้คัดลอกมาวาง และมีชุดทดสอบที่บอกว่าเกณฑ์ข้อไหนล้ม

## หลักฐานที่ต้องมีก่อนแก้ (ขอจากผู้ใช้ถ้าไม่มี)
1. รายงานบั๊ก (ข้อความ error + `ไฟล์:บรรทัด:คอลัมน์` + การกระทำล่าสุด) หรือ
2. ผลทดสอบที่ไม่ผ่าน (ACn + เหตุผล) หรือ
3. ขั้นตอนที่ทำให้เกิด + สิ่งที่คาด + สิ่งที่เกิดจริง

## 4 ขั้น
1. **อ่านหลักฐานให้ครบ** แล้วเปิดไฟล์และบรรทัดที่ระบุ อ่านรอบ ๆ 10 บรรทัด
2. **หาสาเหตุแรก** เขียน 1 ประโยค: "บรรทัด 389 ขาดคำว่า document" ไม่ใช่ "แก้ให้ทำงานแล้ว"
3. **แก้จุดเดียว** ไม่เขียนไฟล์ใหม่ทั้งไฟล์ ไม่เปลี่ยนชื่อ id/ฟังก์ชันที่ใช้อยู่
4. **เพิ่มการทดสอบที่จับบั๊กนี้** (ล้มก่อนแก้ ผ่านหลังแก้) แล้วให้ผู้ใช้กด "ทดสอบ"

## อาการ → สาเหตุที่พบบ่อย

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| `SyntaxError: Unexpected token '.'` | คำหายหน้าจุด `steps:.querySelectorAll` | `steps: document.querySelectorAll` |
| `Unexpected end of input` / `missing ) after argument list` | ปีกกา/วงเล็บไม่ครบ | นับคู่ในฟังก์ชันที่แก้ล่าสุด |
| `Unexpected identifier` | ลืม `,` ระหว่างพร็อพเพอร์ตี หรือ `'` ในข้อความไทย | ตรวจบรรทัดก่อนหน้า |
| `Cannot read properties of null` | id ใน JS ไม่มีใน HTML / script โหลดก่อน element | ตรวจ id, ใส่ `defer` |
| `X is not defined` | ใช้ก่อนประกาศ / สะกดผิด / ลำดับ `<script>` | ค้นชื่อในทุกไฟล์ |
| `X is not a function` | ชื่อซ้ำกับตัวแปร | เปลี่ยนชื่อให้ไม่ชน |
| กดแล้วไม่เกิดอะไร ไม่มี error | ลืม `render()` / ผูก event กับ element ที่วาดใหม่ | delegation บนกล่องแม่ |
| รีเฟรชแล้วข้อมูลหาย | ไม่ได้ `save()` / `storageKey` เปลี่ยน | ตรวจทุกฟังก์ชันเขียน |
| ตัวเลขรวมผิด | บวก string | แปลง `Number()` ใน DB |
| `Failed to fetch` / ข้อความ CORS | API ไม่อนุญาตเบราว์เซอร์ / ออฟไลน์ / URL ผิด | บอกผู้ใช้ตรง ๆ ใช้ API อื่นหรือข้อมูลตัวอย่างที่ติดป้าย |
| `Script error.` ไม่มีรายละเอียด | ไฟล์มาจากคนละที่ (เช่น CDN) | ขอข้อความจาก Console (F12) |

## เมื่อแก้ 2 ครั้งแล้วยังไม่ผ่าน
หยุด รายงาน: สิ่งที่ลอง, ผล, สมมติฐานที่เหลือ และขอรายงานบั๊ก/ผลทดสอบชุดใหม่ ห้ามเดาเปลี่ยนหลายจุดพร้อมกัน
