# app-data — ชั้นข้อมูลแบบละเอียด

ใช้เมื่อแอปมีข้อมูลหลายชนิด มีความสัมพันธ์ หรือมีรายงาน (ดัดแปลงจาก skill backend-api และ requirements-and-acceptance ของ IDE)

## เขียน "สัญญา" ก่อนโค้ด
ก่อนเขียน DB ให้เขียนตารางสั้น ๆ ในคำตอบ:

| ฟังก์ชัน | รับ | คืน | ผิดเมื่อ |
|---|---|---|---|
| `add(input)` | ฟิลด์ที่ผู้ใช้กรอก | `{ok:true,item}` | `{ok:false,errors:{field:ข้อความ}}` |
| `list(query)` | คำค้น / ตัวกรอง | อาร์เรย์ | ไม่ผิด คืน `[]` |

หน้าจอทำตามสัญญานี้เท่านั้น เปลี่ยนสัญญาต้องบอกผู้ใช้

## หลายชนิดข้อมูล
- เก็บแยกเป็นอาร์เรย์ใน state เดียว เช่น `{ customers: [], bookings: [], nextId: 1 }`
- เชื่อมด้วย id ไม่ซ้อนข้อมูลทั้งก้อน: `booking.customerId = 3`
- ลบข้อมูลแม่ที่มีลูกอ้างอยู่: ปฏิเสธพร้อมเหตุผล หรือถามก่อนลบทั้งชุด ห้ามทิ้งลูกที่ชี้ไปหาไม่เจอ
- ฟังก์ชันอ่านที่ใช้บ่อยรวมไว้ใน DB เช่น `bookingsOf(customerId)`, `summary(month)`

## กฎทางธุรกิจอยู่ใน DB
ตัวอย่าง: ห้ามจองเกินที่นั่ง, ห้ามวันที่ย้อนหลัง, ยอดเงินต้องมากกว่า 0
- ตรวจใน `validate` หรือฟังก์ชันเฉพาะ ไม่ใช่แค่ในหน้าจอ
- ข้อความ error บอกตัวเลขจริง: "เหลือ 2 ที่นั่ง แต่จอง 3"

## เปลี่ยนโครงสร้างข้อมูล
- เพิ่มฟิลด์ใหม่: ใส่ค่าเริ่มต้นตอนโหลด `item.status ??= 'pending'` ข้อมูลเก่าไม่พัง
- เปลี่ยนรูปแบบมาก: เปลี่ยน KEY เป็น `app-v2` และเขียนฟังก์ชันย้ายข้อมูลจาก v1 ครั้งเดียว

## รายงานและสรุป
- คำนวณจากข้อมูลจริงทุกครั้ง: `items.reduce((sum, x) => sum + x.amount, 0)`
- เงินคำนวณเป็นจำนวนเต็มหน่วยย่อย (สตางค์) หรือปัดเศษตอนแสดงเท่านั้น
- แสดงตัวเลขด้วย `toLocaleString('th-TH')` วันที่ด้วย `toLocaleDateString('th-TH')`

## นำเข้า / ส่งออก
- ส่งออก JSON ด้วย Blob + ลิงก์ดาวน์โหลด, CSV ใส่ BOM `﻿` ให้ Excel อ่านภาษาไทยได้
- ข้อความที่ขึ้นต้นด้วย `= + - @` ใน CSV ให้เติม `'` นำหน้า กัน Excel ตีความเป็นสูตร
- นำเข้า: ตรวจโครงสร้างก่อนแทนที่ข้อมูล แสดงจำนวนที่จะนำเข้าและให้ยืนยัน

## ข้อมูลจาก API ภายนอก
ใช้ `API.getJSON` ใน SKILL.md หัวข้อ 4 (มี timeout, cache, ข้อความผิดพลาด) เงื่อนไข:
- ไม่ต้องใช้ key ลับ (key ใดที่อยู่ในโค้ดหน้าเว็บ ทุกคนเห็นได้)
- เรียกจากเบราว์เซอร์ได้ (server ตอบ `Access-Control-Allow-Origin`)

| แหล่งข้อมูล (ตรวจเมื่อ 18 พ.ย. 2026) | เรียกจากเบราว์เซอร์ | ตัวอย่าง URL |
|---|---|---|
| Open-Meteo สภาพอากาศ | ได้ ไม่ต้องใช้ key | `https://api.open-meteo.com/v1/forecast?latitude=13.75&longitude=100.5&current=temperature_2m` |
| Open-Meteo คุณภาพอากาศ (PM2.5) | ได้ ไม่ต้องใช้ key | `https://air-quality-api.open-meteo.com/v1/air-quality?latitude=13.75&longitude=100.5&current=pm2_5` |
| Air4Thai กรมควบคุมมลพิษ | ไม่ได้ (ไม่มี CORS ต้องผ่าน server กลาง) | — |

- แสดงแหล่งที่มาและเวลาอัปเดตทุกครั้ง ข้อมูลจาก cache บอกว่าเป็นข้อมูลเก่า
- ค่าที่อ่านได้ตรวจชนิดก่อนแสดง (`typeof v === 'number'`) ไม่แสดง `undefined`/`NaN`
- เคารพเงื่อนไขการใช้งานของผู้ให้บริการ เรียกไม่ถี่ (cache 30 นาที)

## ห้าม
- เก็บรหัสผ่านหรือข้อมูลบัตรใน localStorage
- อ้างว่าข้อมูล "บันทึกขึ้น server" เมื่อเก็บในเบราว์เซอร์
- แต่งตัวเลขหรือรายการที่ผู้ใช้ไม่ได้ให้มา ใช้ข้อมูลตัวอย่างที่ติดป้ายแทน
